Chili Career 官网设计需求
一、网站语言
网站需要支持三种语言：
中文
English
Deutsch
三种语言使用统一的网站结构，具体文案后续逐步完善。

二、网站定位
Chili Career GmbH
总部：德国杜塞尔多夫
定位：
国际化人力资源咨询 / 招聘 / Executive Search
主要服务中国企业在德国及欧洲的人才招聘与 HR 需求。
希望网站整体呈现：
专业、国际化、高端、精准、简洁
不要做成传统招聘网站，也不要有大量职位招聘的感觉。
核心品牌语：
We don’t search. We target.

三、网站导航
第一版导航确定为：
主页
Home / Startseite / 首页
服务
Services / Leistungen / 服务
主要包括：
Recruitment / 招聘
Executive Search
HR Consulting / HR咨询
用户反馈
Client Testimonials / Kundenstimmen / 用户反馈
展示客户评价、合作反馈等。
合作机构
Partners / Partner / 合作机构
展示合作伙伴、机构、协会等 Logo 或名称。
近期活动
Events / Veranstaltungen / 近期活动
展示近期及过去参加的：
路演
论坛
讲座
商务活动
行业活动
后续可以持续更新。
联系我们
Contact / Kontakt / 联系我们
包含简单的联系方式及 Contact Form。

四、首页结构
首页希望比较简洁，主要按照以下逻辑：
01 Hero
Chili Career
European Talent. Strategic Hiring.
We don’t search. We target.
CTA：
Start a Conversation

02 公司定位
简单介绍 Chili Career：
帮助中国企业在德国及欧洲进行人才招聘、Executive Search 和 HR 咨询。
这里重点体现：
China × Europe
以及欧洲本地人才市场专业能力。

03 服务
三个核心服务：
Recruitment
Executive Search
HR Consulting
三个模块可以有简短介绍，并可以点击进入 Services 页面。

04 用户反馈
展示客户评价 / Testimonials。
第一版可以先预留位置，后续逐步增加。

05 合作机构
展示合作机构、合作伙伴、协会等。
主要以 Logo 墙 / 简洁列表形式呈现。

06 近期活动
展示近期参加或举办的活动。
可以使用图片 + 活动名称 + 日期 + 地点。
后续可以持续更新。

07 Contact
最后引导客户联系。
核心 CTA：
Start a Conversation

五、视觉方向
整体希望：
Boutique Consulting / Executive Search / International Business
颜色方向：
黑/ 白 / 红 / Silver / ----或者你的建议？
希望有品牌感，但不要过度奢华。
避免：
传统猎头网站模板
大量招聘类 Stock Photos
握手、面试、办公室开会等俗套图片
过多图标
页面信息过于拥挤
过度使用中国元素
整体希望体现：
一家总部位于德国、连接中国企业与欧洲人才市场的精品 HR Consulting / Executive Search 公司。

六、设计阶段
第一阶段重点是：
网站结构 + 页面设计 + 三语架构 + 视觉风格。
具体文案、客户评价、合作机构、活动内容等后续逐步补充。
网站整体保持：
简洁、专业、克制、有品牌感。
